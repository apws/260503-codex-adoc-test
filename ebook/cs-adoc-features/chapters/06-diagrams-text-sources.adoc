== 06 Text diagram sources: Mermaid, PlantUML, Graphviz

[.page-sheet]
****
AsciiDoc can hold diagram source directly. Rendering those blocks needs an extra diagram extension or external renderer.

[.warning-card]
This scaffold does **not** install diagram renderers yet. It demonstrates the source pattern only, to avoid a heavy first toolchain.
