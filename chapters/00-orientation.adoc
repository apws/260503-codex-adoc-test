== 00 Orientation: what this scaffold is

[.page-sheet]
****
[.feature-card]
The target is a **text-source document system** for compact pages/sheets:

[.compact-list]
* source: `.adoc`
* style: custom CSS with inverted heading bars
* preview: Chrome Asciidoctor.js extension or generated HTML
* automation: Deno 2 + Asciidoctor.js
* diagrams: SVG/PNG assets, Excalidraw source, text diagram source
* PDF: browser print-to-PDF first
